Welcome to WordCraft ✍

WordCraft is a free, open-source word processor built for writers, developers, and teams who need professional document editing without subscriptions or data collection.

✦ Key Features

  • Rich formatting — Bold, italic, underline, colors, highlights
  • AI Writing Assistant — Summarize, rewrite, expand any selection
  • Focus Mode — Distraction-free writing environment
  • Dark Mode — Easy on the eyes for night writing
  • Mobile-First — Full editing on phone or tablet
  • Track Changes — Review and accept/reject edits
  • Privacy-first — No telemetry, no account required

✦ Getting Started

Click anywhere and start typing. Use the toolbar for formatting, or use keyboard shortcuts. Select text to see the floating mobile toolbar on phones.

Tip: Use Focus Mode (F11 or ⧗ button) for a distraction-free writing environment.
